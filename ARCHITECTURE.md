# Architecture
Operational: standard Next.js App Router, TypeScript/React, OpenNext adapter, Cloudflare Workers (auntyalice), one repository and one Worker, GitHub Actions, Git-connected main. See DEPLOYMENT.md. Lockfile/version pinning outstanding. Planned: Neon PostgreSQL per environment, R2 for approved images/PDFs, school-owned YouTube, Better Auth candidate, Resend candidate, Paystack candidate. No provisioning or DNS changes without approval.

Current app/ routes: /, /primary, /secondary, /admissions, /school-life, /learn, /learn/[exam], /learn/[exam]/[subject], /learn/lesson/[slug]. Shared UI/domain logic. Proposed root auntyalice.sch.ng (unverified); primary., secondary., learn., portal. (deferred). No exam subdomains. Academy canonical hostname paths /waec, /jamb, /neco, /bece, /common-entrance and /lesson/[slug]; /library and /cbt later. Keep local/Workers paths until DNS configured; trusted allowlisted hostname mapping and canonical metadata/redirects, never trust arbitrary forwarded hosts or authorize by hostname. One deployment initially; separate product layouts and private authorization boundaries.

Planned data: schools, sections, users, memberships, roles, staff profiles, pages, events, clubs, media, subjects, grades, topics, syllabus versions/mappings, lessons/revisions, questions/revisions, publication reviews, audit events. Later learners, guardians/links, enrollments, attempts, assignments, attendance, grades, orders, payment events. Avoid unused tables; migrations, separate staging/prod credentials, backups and restore tests; no production migration without approval. Server-side cross-school/role isolation tests. Staff MFA where supported, host-scoped cookies and explicit later SSO design. Validate/rate-limit inputs, sanitize rich text, CSRF/CSP, private storage/signed URLs, audit without secrets or unnecessary child data. Review Nigeria Data Protection Act obligations, lawful basis, consent where applicable, retention/deletion, processors/transfers and privacy notice with school/legal advisor. No real pupil fixtures or public adult-minor direct messaging.

Commerce: catalogue and verified WhatsApp enquiries first; verified merchant links later. School Ledger candidate source of stock truth, audit interface before integration; verified webhooks, idempotency, bank reconciliation, refunds and order/stock state machine. No live transactions without approval.

Testing: strict application typecheck, generated Wrangler runtime declarations, skipLibCheck for DOM/Workers declaration conflicts, Next/OpenNext build, workerd route tests, browser/mobile/accessibility/performance, permissions and publication leakage. Public-only versioned offline cache; test logout/stale cache/update. Monitor errors, uptime and privacy-preserving metrics.
